# Changelog

## 1.5.0
- Состояние теперь отражает скорость и исправность ПК. Новые проверки: здоровье диска (SMART), тип системного диска (HDD / SSD), объём и поколение ОЗУ (DDR / DDR2 / DDR3 / DDR4 / DDR5), число потоков процессора. 🟥 «Опасно» — только неисправное или слишком слабое оборудование (SMART-сбой диска, ОЗУ меньше `checks.ramGbBad` = 4 ГБ, DDR / DDR2); 🟨 «Терпимо» — HDD, ОЗУ меньше `checks.ramGbWarn` = 8 ГБ, DDR3, слабый процессор (`checks.cpuThreadsWarn`) и **все** программные проблемы (антивирус, поддержка ОС, место на диске, аптайм, брандмауэр); `excel.softwareCanBeRed` разрешает красный и для них.
- Если данные недоступны (виртуальная машина, старая ОС, нет прав), соответствующая проверка пропускается.
- Значение `checks.ramGbWarn` по умолчанию изменено с 4 на 8 ГБ.

## 1.4.0
- Столбец «Состояние рабочей станции»: три категории с цветом — `Опасно:` (красный), `Терпимо:` (жёлтый), `Нет проблем` (зелёный). Причины переформулированы так, чтобы не путать с состоянием диска («Мало места на C: (4% своб.)», «Мало ОЗУ: 2 ГБ», «Без перезагрузки 45 дн.»). Подсветка — условное форматирование (добавляется один раз, работает и для старых текстов «Плохое:/Внимание:/Хорошее»). Значение по умолчанию `excel.defaultState` — «Нет проблем»; `excel.stateMaxItems` по умолчанию 2.
- Служебные файлы вынесены из `Raports\` в отдельную папку `Service\` (`paths.serviceDir`): `state`, `backup`, `debug`, `last_inventory.json`, `last_run.log`, `pending_rows.csv`, `remote_search.txt`. В `Raports\` остаются только отчёты. Старые файлы из `Raports\_*` переносятся автоматически при первом запуске.

## 1.3.0
- Столбец «Состояние рабочей станции» теперь заполняется по реальным результатам быстрой проверки (коротко: `Внимание: Диск 12%, Аптайм 45д`, `Плохое: Нет антивируса`, иначе `Хорошее`). Текст, написанный вручную, не затирается; автотекст обновляется при каждом запуске. Число причин — `excel.stateMaxItems`.
- Новые столбцы «Серийный номер» и «Модель» (добавляются в конец существующей таблицы автоматически). Строка ищется по имени ПК, затем по серийному номеру; одинаковое имя при другом серийном номере распознаётся как другой ПК. Старый `excel.headers` из 11 пунктов остаётся рабочим.
- Паспорт ПК можно называть по серийному номеру: `pc_info_<серийный номер>.json`.
- HTML-отчёт открывается в Google Chrome (`ui.browser`: `chrome` по умолчанию или `default`); если Chrome не найден — в браузере по умолчанию.
- `build.ps1` и `src\` не входят в архив «Download ZIP» (`.gitattributes`, `export-ignore`).

## 1.2.0 — подготовка к публичному релизу
- Нейтральные формулировки: функции, переменные, ключи `config.json`, сообщения журнала и заголовки таблицы описывают категории (`remoteAccessDetect`, `diskProtectionDetect`, `hardwareCollector`), а не конкретные продукты.
- Технические сигнатуры распознавания установленного ПО вынесены в единый блок `$script:Sig` (`src/Collectors.ps1`).
- Параметр `-NoHopCli` заменён на `-NoRemoteCli`; ключи `features.anyDesk*`/`hopToDesk*`/`freezeDetect`/`freeze.*` заменены на `features.remoteAccessDetect`, `features.remoteAccessCli`, `features.diskProtectionDetect`, `diskProtectionDetect.*`.
- Добавлена проверка Windows Unified Write Filter через CIM.
- Заголовки таблицы по умолчанию: «Удалённый доступ 1 (ID)», «Удалённый доступ 2 (ID)», «Защита диска»; лист и файл — «Инвентаризация». Для существующих таблиц задайте прежние заголовки в `excel.headers`.
- Добавлены LICENSE (MIT), `.gitignore`, пример паспорта `Passports/pc_info.example.json`, README.

## 1.1.0
- Быстрая проверка: пороги в секции `checks` (`uptimeDaysWarn`, `ramGbWarn`, `diskFreePctWarn`, `diskFreePctBad`, `diskFreeGbBad`, `osSupportWarnDays`, `changeFreeGb`, `osSupport`).
- Поддержка ОС определяется по сборке и редакции Windows; состояние антивируса — из SecurityCenter2; брандмауэр — с запасным чтением из реестра.
- Отчёт: блок «что исправить в первую очередь», «что изменилось с прошлого отчёта» (снимок в `Raports\_state`), быстрая таблица программ, поиск, печатная версия.
- Excel: столбцы ищутся по тексту заголовка; записываются только изменённые ячейки; защищённый лист и объединённые ячейки останавливают запись с понятным сообщением; обновление делается на копии с проверкой.
