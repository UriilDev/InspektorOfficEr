## 📋 О проекте

**InspektorOfficEr** собирает сведения об оборудовании и состоянии Windows, строит автономный HTML-отчёт и ведёт таблицу инвентаризации в формате Excel — по одной строке на каждый ПК. Запускается с USB-носителя или из любой папки, ничего не устанавливает и не требует Excel на проверяемом ПК.

> **Только штатные возможности Windows.** Инструмент написан на Windows PowerShell и использует CIM/WMI, реестр и системные службы. В проекте **нет поставляемых сторонних исполняемых файлов, модулей и библиотек**, а для работы не нужны коммерческие лицензии.

## ✨ Возможности

| | Возможность | Описание |
|---|---|---|
| 🖥️ | **Аппаратный сборщик** (`hardwareCollector`) | ОС, системная плата, BIOS, процессор, память, диски, видео, сеть, батарея — через CIM/WMI |
| ✅ | **Быстрая проверка** | Аптайм, объём ОЗУ, свободное место, срок поддержки ОС, антивирус, брандмауэр. К каждой проблеме — короткая подсказка; пороги настраиваются |
| 🔄 | **Что изменилось** | Сравнение с предыдущим отчётом этого ПК: ОС, ОЗУ, диски, установленные и удалённые программы |
| 📊 | **Инвентаризация в Excel** | Столбцы ищутся по заголовку, ручные данные не затираются; перед записью — резервная копия и самопроверка файла |
| 🪪 | **Паспорт ПК** | Этаж / помещение / рабочее место / пользователь — из JSON-файла или разового ввода |
| 🔎 | **Детектор удалённого доступа** (`remoteAccessDetect`) | Определяет идентификаторы установленных на ПК средств удалённого доступа и заносит их в таблицу автоматически |
| 🛡️ | **Детектор защиты диска** (`diskProtectionDetect`) | Windows Unified Write Filter (CIM) и признаки ПО защиты диска: службы, драйверы, установленные программы |
| 🧾 | **Журнал и диагностика** | Уровни логирования, режим `-Diagnose` |

Все детекторы работают **только на чтение** и не изменяют систему.

## 🚀 Быстрый старт

1. Скопируйте проект на USB-носитель или в любую папку.
2. Запустите **`Inspektor.bat`** — он запросит права администратора и выполнит `Inspektor.ps1`.
   Либо вручную из консоли PowerShell:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Inspektor.ps1
   ```

3. Результаты появятся рядом со скриптом:

   | Файл | Содержимое |
   |---|---|
   | `Raports\PC-001_report_20260101.html` | автономный HTML-отчёт |
   | `Инвентаризация.xlsx` | таблица инвентаризации |

> 💡 Права администратора нужны для полного набора данных (часть классов WMI и профили служб). Без них инструмент работает, но выводит предупреждение.

### Параметры командной строки

| Параметр | Назначение |
|---|---|
| `-SkipReport` | только инвентаризация |
| `-SkipExcel` | только HTML-отчёт |
| `-NoRemoteCli` | не обращаться к интерфейсу командной строки установленных программ (только чтение файлов и реестра) |
| `-NoPrompt` | не запрашивать паспорт ПК |
| `-Diagnose` | подробный журнал в `Raports\_debug\` |

**Коды завершения:** `0` — успех · `3` — ошибка отчёта · `5` — Excel не обновлён (строка сохранена в `_pending_rows.csv`).

### Пример паспорта ПК

Файл `Passports/pc_info.example.json` (все данные вымышленные):

```json
{
  "Этаж": "1",
  "Помещение": "3",
  "Рабочее место": "2",
  "Пользователь": "test_user"
}
```

### Пример вывода

```text
InspektorOfficEr v1.2.0
--- inventory ---
  passport  : Passports\pc_info_PC-OFFICE-02.json
  PC / user : PC-OFFICE-02 / test_user
  floor/room/place : 1 / 3 / 2

  disk prot.: Нет
Result: report=0, inventory=0, total 6s
```

## ⚙️ Настройка

Файл `config.json` необязателен: значения по умолчанию встроены в скрипт.

| Раздел | Что настраивает |
|---|---|
| `features` | `hardwareCollector`, `excel`, `remoteAccessDetect`, `remoteAccessCli`, `diskProtectionDetect` |
| `remoteAccessDetect` | `extraConfigDirsA`, `extraPathsA`, `extraPathsB` — нестандартные папки настроек и пути к программам |
| `diskProtectionDetect` | `extraProducts` (`name`, `pattern`, `paths`), `disableBuiltin`, `excludePattern`, `enabledText` |
| `checks` | пороги быстрой проверки (аптайм, ОЗУ, свободное место, срок поддержки ОС) |
| `excel` | имя листа, заголовки столбцов, состояние по умолчанию |
| `paths` | папки отчётов и паспортов |
| `timeouts`, `log`, `backup`, `ui` | таймауты, уровень журнала, число резервных копий, поведение после запуска |

> Параметры командной строки всегда приоритетнее `config.json`.

## 🏗️ Архитектура

```text
Inspektor.bat       запуск с запросом прав администратора
Inspektor.ps1       единый переносимый скрипт (ГЕНЕРИРУЕТСЯ из src\)
build.ps1           сборка Inspektor.ps1 (-Check — проверка актуальности)
config.json         настройки
src\
 ├─ Core.ps1        общие функции и состояние
 ├─ Log.ps1         журнал, диагностика
 ├─ Context.ps1     конфигурация, параметры, пути
 ├─ Checks.ps1      быстрая проверка
 ├─ Changes.ps1     сравнение с прошлым отчётом
 ├─ Report.ps1      HTML-отчёт (CIM/WMI)
 ├─ Collectors.ps1  детекторы: удалённый доступ, защита диска
 ├─ Passport.ps1    паспорт ПК
 ├─ Xlsx.ps1        запись в .xlsx без установленного Excel (OpenXML)
 ├─ Inventory.ps1   формирование строки инвентаризации
 └─ Main.ps1        точка входа
Passports\          локальные паспорта ПК (не коммитятся)
Raports\            отчёты, журналы, состояние (не коммитятся)
```

**Разработка:** правки вносятся в `src\`, затем выполняется `.\build.ps1`. Файлы `.ps1` хранятся с окончаниями строк CRLF (см. `.gitattributes`); исходники содержат только ASCII — кириллица задаётся через `\uXXXX`.

<details>
<summary><b>7. Республика Молдова: что учитывать при использовании</b></summary>

**Персональные данные.** Имя пользователя, привязка ПК к рабочему месту и имя ПК могут относиться к персональным данным. С **23 августа 2026 г.** в Республике Молдова действует [Закон № 195/2024 о защите персональных данных](https://moldpres.md/eng/society/new-rules-on-personal-data-protection-enter-into-force-in-moldova-as-of-august-23) (заменяет Закон № 133/2011). Надзорный орган — [Национальный центр по защите персональных данных](https://datepersonale.md/) (НЦЗПД). Если инструмент применяется в организации, она выступает **оператором** (контролёром) данных и, как правило, должна:
- определить цель и правовое основание обработки (например, учёт и безопасность ИТ-активов);
- собирать только необходимый минимум (принцип минимизации) — при желании оставьте поле «Пользователь» пустым;
- письменно или иным надлежащим способом **информировать сотрудников**, какие данные собираются, зачем и как долго хранятся;
- обеспечить организационные и технические меры защиты отчётов (ограниченный доступ, шифрование носителя, учёт копий);
- определить срок хранения и удалять устаревшие отчёты;
- при инциденте с персональными данными действовать по процедуре закона, в том числе рассмотреть уведомление НЦЗПД в установленный срок (по закону — как правило, не позднее 72 часов с момента, когда стало известно);
- при передаче данных подрядчику заключить договор обработки.

**Несанкционированный доступ.** Доступ к компьютерной информации без права или с превышением прав может влечь ответственность по Уголовному кодексу РМ (в частности, ст. 259 — незаконный доступ к компьютерной информации). Запускайте инструмент только на ПК, доступ к которым вам разрешён.

**Авторское право и программное обеспечение.** Использование и распространение программ регулируется Законом РМ № 139/2010 об авторском праве и смежных правах и лицензиями правообладателей. Инструмент не проверяет и не гарантирует лицензионную чистоту ПО на проверяемом ПК.

**Трудовые отношения.** Если ПК закреплены за работниками, порядок их проверки и сбора сведений о рабочем месте фиксируйте во внутренних правилах (политика использования ИТ-ресурсов) и доводите до сведения работников.

> Нормы законодательства могут меняться. Актуальные тексты ищите в [Государственном регистре правовых актов РМ](https://www.legis.md/) и на сайте [НЦЗПД](https://datepersonale.md/).
