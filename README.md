InspektorOfficEr собирает сведения об оборудовании и состоянии Windows, строит автономный HTML-отчёт и ведёт таблицу инвентаризации в формате Excel. Работает с обычного USB-носителя или локальной папки, ничего не устанавливает.

> **Только штатные возможности Windows.** Инструмент написан исключительно на Windows PowerShell и использует CIM/WMI, реестр и системные службы. Он **не содержит и не поставляет сторонних исполняемых файлов (.exe)** и не требует коммерческих лицензий. Для распознавания уже установленного на ПК ПО может обратиться к его штатному интерфейсу командной строки; это отключается параметром `-NoRemoteCli` или `features.remoteAccessCli: false`.

## ✨ Возможности (Features)

- **Аппаратный сборщик (`hardwareCollector`)** — ОС, материнская плата, BIOS, процессор, память, диски, видео, сеть, батарея (CIM/WMI).
- **Быстрая проверка** — аптайм, объём ОЗУ, свободное место, срок поддержки ОС, антивирус, брандмауэр; к каждой проблеме — короткая подсказка. Пороги настраиваются.
- **Что изменилось** — сравнение с предыдущим отчётом этого ПК (ОС, ОЗУ, диски, программы).
- **Инвентаризация в Excel** — одна строка на ПК; столбцы ищутся по заголовку, ручные данные не затираются, перед записью создаётся резервная копия и выполняется самопроверка.
- **Паспорт ПК** — этаж / помещение / рабочее место / пользователь из JSON-файла или разового ввода.
- **Детекторы (нативные, только чтение):**
  - `remoteAccessDetect` — ID установленных на ПК средств удалённого доступа (из текстовых настроек или через штатный CLI самой программы, если он доступен) — заносится в таблицу автоматически;
  - `diskProtectionDetect` — Windows Unified Write Filter (CIM) и признаки ПО защиты диска (службы, драйверы, установленные программы).
- **Журнал и диагностика** — уровни логирования, режим `-Diagnose`.

## 🚀 Быстрый старт (Quick Start)

1. Скопируйте проект на USB-носитель или в любую папку.
2. Запустите `Inspektor.bat` — он запросит права администратора и выполнит `Inspektor.ps1`.
   Или вручную:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\Inspektor.ps1
   ```
3. Результаты появятся рядом со скриптом:
   - `Raports\PC-001_report_20260101.html` — HTML-отчёт;
   - `Инвентаризация.xlsx` — таблица инвентаризации.

### Параметры

| Параметр | Назначение |
|---|---|
| `-SkipReport` | только инвентаризация |
| `-SkipExcel` | только HTML-отчёт |
| `-NoRemoteCli` | не вызывать CLI установленных программ (только чтение файлов и реестра) |
| `-NoPrompt` | не запрашивать паспорт ПК |
| `-Diagnose` | подробный лог в `Raports\_debug\` |

Коды завершения: `0` — успех, `3` — ошибка отчёта, `5` — Excel не обновлён (строка сохранена в `_pending_rows.csv`).

### Пример паспорта и вывода

`Passports/pc_info.example.json`:

```json
{
  "Этаж": "1",
  "Помещение": "3",
  "Рабочее место": "2",
  "Пользователь": "test_user"
}
```

Консольный вывод (обезличенный):

```text

--- inventory ---
  PC / user : PC-OFFICE-02 / test_user
  floor/room/place : 1 / 3 / 2
  remote    : test-app: 123456789

```

## ⚙️ Настройка (`config.json`)

Все ключи необязательны — значения по умолчанию встроены. Основные разделы:

| Раздел | Что настраивает |
|---|---|
| `features` | `hardwareCollector`, `excel`, `remoteAccessDetect`, `remoteAccessCli`, `diskProtectionDetect` |
| `remoteAccessDetect` | `extraConfigDirsA`, `extraPathsA`, `extraPathsB` |
| `diskProtectionDetect` | `extraProducts`, `disableBuiltin`, `excludePattern`, `enabledText` |
| `checks` | пороги быстрой проверки |
| `excel` | имя листа, заголовки, состояние по умолчанию |
| `paths` | папки отчётов и паспортов |

Нестандартные папки настроек и пути к программам задаются в `remoteAccessDetect.extraConfigDirsA`, `extraPathsA`, `extraPathsB`; свои шаблоны защиты диска — в `diskProtectionDetect.extraProducts` (`name`, `pattern`, `paths`).

## 🏗️ Архитектура (Architecture)

```text
Inspektor.bat      запуск с повышением прав
Inspektor.ps1      ГЕНЕРИРУЕМЫЙ единый переносимый скрипт
build.ps1          сборка Inspektor.ps1 из src\ (-Check — проверка актуальности)
config.json        настройки
src\
  Core.ps1         общие функции и состояние
  Log.ps1          журнал, диагностика
  Context.ps1      конфигурация, параметры, пути
  Checks.ps1       быстрая проверка
  Changes.ps1      сравнение с прошлым отчётом
  Report.ps1       HTML-отчёт (CIM/WMI)
  Collectors.ps1   детекторы: удалённый доступ, защита диска (сигнатуры — одним блоком в начале файла)
  Passport.ps1     паспорт ПК
  Xlsx.ps1         запись в Excel без Excel (OpenXML)
  Inventory.ps1    сборка строки инвентаризации
  Main.ps1         точка входа
Passports\         локальные паспорта ПК (не коммитятся)
Raports\           отчёты, логи, состояние (не коммитятся)
```

Правка вносится в `src\`, затем `.\build.ps1`. Файлы `.ps1` хранятся с окончаниями строк CRLF (см. `.gitattributes`), исходники — только ASCII (кириллица через `\uXXXX`).

## 🔒 Юридическая информация и безопасность (Legal & Security)

**Лицензия.** Программа распространяется по лицензии [MIT](LICENSE) «как есть», без каких-либо гарантий.

**Зависимости.** Нет сторонних модулей, библиотек и поставляемых исполняемых файлов. Используются только компоненты Windows: PowerShell, .NET Framework из состава ОС, CIM/WMI, реестр, службы.

**Какие данные собираются.** Сведения об оборудовании и ОС, список установленных программ, имя ПК и пользователя, состояние защитных функций. Данные получаются через стандартные интерфейсы ОС, сохраняются **только локально** в папке инструмента и никуда не передаются: сетевых запросов нет.

**Сторонние программы на ПК.** Проект не включает, не распространяет и не модифицирует чужое ПО и не связан с его правообладателями. Инструмент лишь считывает информацию о программах, уже установленных на проверяемом ПК. Использование таких программ регулируется их собственными лицензиями; ответственность за наличие лицензий на установленное ПО несёт владелец ПК.

**Сигнатуры.** Технические идентификаторы для распознавания установленного ПО (имена файлов, служб, ключ CLI) собраны в одном блоке `$script:Sig` в `src/Collectors.ps1`; они используются только для чтения и необходимы для совместимости. Упоминание наименований — номинативное, без указания на связь с правообладателями.

**Что не делает.** Не обходит защиту, не повышает привилегии самостоятельно (права администратора запрашивает `Inspektor.bat`), не изменяет настройки системы, не устанавливает ПО, не читает пароли и содержимое пользовательских документов.
